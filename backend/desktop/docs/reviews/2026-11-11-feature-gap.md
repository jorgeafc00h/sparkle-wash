# SparkleWash Desktop: feature gap report (2026-11-11)

Scope: `backend/desktop` on `main` (9a11a99) against the SparkleWash platform (API, web console, iOS, landing, specs).
Read-only review: nothing was implemented or run; findings come from reading code and docs. Paths are relative to
`backend/desktop/` unless prefixed `api:` (`backend/src/carwash-api/`), `web:` (`web/src/`), `ios:` (`SparkleWash-iOS/Views/`).

Priority: **P0** blocks a carwash from using the desktop, or risks money or data integrity. **P1** important. **P2** nice to have.
Effort: **S** < 1 day, **M** 1-4 days, **L** > 4 days.

## 0. Summary

The desktop is a good **counter terminal**: walk-in work tickets, offline outbox, SSE sync, job board, "Cobrar lavado" in the POS,
thermal work ticket. It is not yet a SparkleWash **staff console**: it has no camera-arrival review, no inventory, no admin, no plate history.
The bigger risks are the inherited Facturas Simples layer (tier gates, upstream sign-in, branding) and four integrity holes
(viewer role, void/return, tenant switch, double charge).

Counts in the backlog (section 6): **P0 6, P1 15, P2 11 (32 items)**.

## 7. Recommended order of work

1. **Safety first (one sprint):** G01 roles, G04 tenant isolation, G06 sign-in path and default URL, G05 overpayment guard. Small, independent, and each closes a way to take wrong money or leak between carwashes.
2. **Money loop:** G02 void/return reversal (API first, then desktop), plus G09 discount/split fixes and the tests in section 5 for them.
3. **Unblock DTE for a carwash:** G03 tier gates (decision: local entitlements), then G08 package mapping so consolidation groups cleanly; G20/G21 along the way.
4. **Make it look like SparkleWash:** G10, G11, G12, G13 in one pass behind a single build flag; owner decisions needed on telemetry (G12) and PDF logo (G13) before starting.
5. **Operations hardening:** G14 multi-register, G15 session UX, G16 outbox panel, G18 signing and OAuth publishing (long lead time: certificate purchase and consent-screen verification; start it in parallel with step 1).
6. **Parity features:** G07 camera arrivals review (biggest L), then G22 quick links, G23 history, G17 inventory after the stock-system decision.
7. **Polish:** G25 barcode, G27 a11y, G24 English, G26 extra payment methods, remaining P2.
