## 1. Product

Car Spa is a **real-time IoT carwash management platform**. Customers watch their car
get washed via a live camera and station dashboard; owners monitor PSI pressure, soap level,
station occupancy, revenue and payment verification from an admin bento-grid. It runs as a
PWA (installable, works offline via a cache-first service worker) and streams station feeds
over WebSocket, with an ESP32-CAM edge node providing the video feed and ADC sensor readings.

**Design philosophy (from `design-system/sparklewash/MASTER.md`):** OLED-first dark theme
(`#0a0c10` background), `#688ef9` primary accent, 4×4 grid spacing, Poppins + Inter font
stack. Single-source-of-truth tokens live in `design-system/sparklewash/SYSTEM-ARCHITECTURE.md`.

## 2. Architecture Layers

### Layer 1 — Edge (`esp32-firmware/`)
- **Board:** ESP32-CAM dev module, OV2640 camera, ADC (GPIO5) rain probe, water-level probe (GPIO6).
- **SDK:** ESP-IDF (CMake `components/`), no Arduino. Firmware sends `multipart/form-data` HTTP photos to the backend upload endpoint and streams tiny JSON frames (~38 KB/s) to the broker.
- **Firmware:** `esp32-firmware/main.c`, `config/`, `components/`; flashing via `esp32-firmware/flash.sh`. See `docs/ESP32-CAM-FIRMWARE-DESIGN.md`, `docs/ESP32-CAM-SYSTEM-DESIGN.md`, `docs/ESP32-CAM-SYSTEM-DESIGN-v2.md`.

### Layer 2 — Backend (`backend/src/carwash-api/`)
- **Runtime:** .NET 10 Minimal API, `net10.0`, listens on `:8080` (`ASPNETCORE_URLS`).
- **OpenAPI 3.1** auto-generated by `Microsoft.AspNetCore.OpenApi` → `/openapi.json`.
- **WebSocket bridge `GET /ws/app-station-streaming/{stationId}`** re-broadcasts MQTT→WS frames with ~360 Hz keepalive.
- **Prometheus `/metrics/daily-wash-counts`**, `/healthz`.
- **MQTT→WebSocket bridge** (`WsController.cs`) with SemaphoreSlim-ordered publishes, MQTT broker bridge mode.
- Deps: `Microsoft.AspNetCore.OpenApi`. (No MQTTnet dependency; MQTT handled by the broker/edge.)
- **Contract:** `docs/API-CONTRACT.md`.

### Layer 3 — Frontend (`frontend/`)
- **Stack:** React 19 + Vite 5 + TypeScript (tsc clean, 0 errors) + Tailwind.
- **PWA:** `public/sw.js` cache-first static / network-first API, degrades to 3s polling.
- **Components:** `StationCard.tsx` (WebSocket payload lifecycle + state machine), gauge cards (PSI >60 red / <45 yellow; soap >55dm green / 35–55 yellow / <35 red), admin bento-grid dashboard, customer QR→receipt PWA flow.
- **Build:** `npm run build` outputs to `../backend/static/wwwroot` (SPA fallback serves `index.html`).

## 4. Cost-Effective Hosting (Azure vs Oracle)

See `docs/HOSTING-COST-AUDIT.md`. **Recommendation:** start on Oracle ARM Free
Tier (4 vCPU + 24 GB RAM always-free, $0/mo compute, only ~$5/mo egress) → migrate to
Azure Container Apps at the 18-month free-tier trigger. Both targets accept the same ARM64
container; only the ingress domain changes (`<app>.azurecontainerapps.io`).

**Deployment:** multi-stage Docker build → `docs/DEPLOY.md` (Oracle OCI → Azure ACA).
