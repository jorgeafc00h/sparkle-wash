# Car Spa brand assets

Vectorised from the owner's logo (`car-spa-logo.jpeg`, 2026-11-12). Use the SVGs; never re-trace or recolour.

| File | Use |
|---|---|
| `car-spa-logo.svg` | Full lockup (mark + CAR SPA + AUTOMOTIVE CARE) on light backgrounds |
| `car-spa-logo-ondark.svg` | Full lockup on dark backgrounds (blue → white) |
| `car-spa-mark.svg` / `car-spa-mark-ondark.svg` | Mark only (headers, favicons, small sizes) |
| `car-spa-app-icon.svg`, `car-spa-app-icon-1024.png` | Square, opaque app icon (mark on white) |

Colours: orange `#FB5A00` ("CAR", left swoosh), royal blue `#0142A8` ("SPA", S-swoosh),
teal rules `#3F838C` / `#03515B`, tagline ink `#1C1C1C`. Tagline: "AUTOMOTIVE CARE" (Spanish prose: "cuidado automotriz").
Keep clear space of at least the height of the "C" around the lockup; minimum mark width 24 px.
